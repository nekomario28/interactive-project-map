# Deferred visual style ideas

Status: **idea backlog only — not active implementation work**

Visual-style expansion is intentionally deferred until higher-value navigation and focus functionality is finished and validated. No new production preset should be added from this document without a new evidence pass against the current production layouts.

## Magic Circle / Spell Array

Keep a future **magic-circle / spell-array** presentation idea in the backlog.

The useful concept is not decorative fantasy art by itself. If revisited, the visual language should map directly to Project Map semantics:

- Owner = central core / caster;
- Category = sector, formula ring, or major sigil;
- Repository = readable node/anchor, not tiny rune text;
- repository relation = activation path shown on demand;
- activity = restrained pulse/charge;
- focus = a bounded activation sequence that reveals the selected path;
- archived repository = visibly inactive/dim state.

Possible directions worth re-testing later:

1. **Magic circle** — category sectors around the owner with very sparse construction geometry.
2. **Activation sequence / CAD-like formula** — categories as explicit execution blocks and repositories as operands/targets.
3. **Explosion / cast feedback** — selection-only charge → lock → release feedback, never an always-on effect.
4. **SF × magic hybrid** — precise technical diagram language with arcane geometry only where it communicates structure.

## Hard acceptance rule

A future style must beat or materially complement existing Galaxy Systems / Galaxy Hybrid / Obsidian-like behavior on at least one real product goal:

- faster Category/Repository identification;
- clearer hierarchy or relation disclosure;
- stronger profile identity without reducing readability;
- better focus/selection feedback;
- better dense-profile behavior.

A style is **not** worth adding only because it looks different.

The failed Arcane/Anime-magic prototypes remain useful research evidence, but they are not production candidates. Their reusable functional lessons — Category navigator, disclosure separate from focus, context-preserving selection, and bounded focus feedback — should be developed independently of visual style work.
